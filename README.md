Fuzzy Logic Car Price Estimator

Overview

A Python-based application that estimates car prices using Fuzzy Logic. The project demonstrates how fuzzy logic principles can be applied to handle approximate inputs and produce an estimated car price.

The application includes a calculation engine and a graphical user interface built with Tkinter.

Project Structure

- "fuzzy_engine.py" – Contains the fuzzy logic calculation engine responsible for processing inputs and estimating car prices.
- "gui.py" – Provides the graphical user interface through which users can enter car details and view the estimated price.

Technologies Used

- Python
- Fuzzy Logic
- Tkinter

How to Run

1. Make sure Python is installed.

2. Install the required library:
   
   pip install -r requirements.txt

3. Run the graphical interface:
   
   python gui.py

Key Concepts

- Fuzzy Logic principles
- Fuzzy input processing
- Rule-based estimation
- Separation of calculation logic from the user interface
